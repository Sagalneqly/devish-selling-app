How to install

  1. Download the file. Tap the orange button above. If your browser warns that the file can harm your device, choose Download anyway.
  2. Open it. Tap the finished download, or find D3X-WAY.apk in your Downloads folder.
  3. Allow the install. If Android asks, allow your browser to install apps from this source, then go back and tap Install.
  4. Updating? Install over the old app. Your data stays. If Android says the app was not installed, remove the old app first, then install again.
